# actions, messages, functions (generator): collection-bound operations are emitted as unbound URLs (ValidateSavedQuery, CreateMultiple, UpdateMultiple, …)
<!-- labels: bug,P1,pkg:actions,pkg:messages,pkg:functions,generator,fetchxml-studio -->

## Summary

Operations bound to an entity collection must be called as
`POST /{entityset}/Microsoft.Dynamics.CRM.{Name}`. The generators treat collection binding as
unbound:

- `ValidateSavedQueryAction`: `POST /ValidateSavedQuery`. Expected `POST /savedqueries/Microsoft.Dynamics.CRM.ValidateSavedQuery`.
- `CreateMultipleAction`: `POST /CreateMultiple`, and the constructor has no entity-set argument.
  The README shows `new CreateMultipleAction("accounts", accounts)`, which doesn't match the code.
- `messages` `ValidateSavedQueryRequest` has the same problem.

## Why FetchXML Studio needs this

Save view validates the query with `ValidateSavedQuery` (bound to `savedqueries`) before saving.

## Repro (`repro/gen/02-actions.mjs`, `06-entityref-and-messages.mjs`)

```
[ValidateSavedQuery] POST https://org.crm.dynamics.com/api/data/v9.2/ValidateSavedQuery
[CreateMultiple]     POST https://org.crm.dynamics.com/api/data/v9.2/CreateMultiple
ValidateSavedQueryRequest -> https://org.crm.dynamics.com/api/data/v9.2/ValidateSavedQuery
```

## Root cause

- `tools/generate-sdk-types/src/generators/actions-generator.ts:318-321` (comment: "Collection-bound
  (treated as unbound for URL)")
- `messages-generator.ts:343-346`
- `functions-generator.ts:359-361`

## Proposed fix

- For collection binding to a concrete type, emit
  `` `${baseUrl}/${entitySetMap[type]}/Microsoft.Dynamics.CRM.${name}` ``.
- For `Collection(mscrm.crmbaseentity)` (the *Multiple messages), add a required `entitySetName`
  constructor argument.

- [ ] `ValidateSavedQueryAction` produces `/savedqueries/Microsoft.Dynamics.CRM.ValidateSavedQuery`.
- [ ] `new CreateMultipleAction('accounts', targets)` produces `/accounts/Microsoft.Dynamics.CRM.CreateMultiple`.
- [ ] A snapshot test lists every bound-collection operation's URL.
