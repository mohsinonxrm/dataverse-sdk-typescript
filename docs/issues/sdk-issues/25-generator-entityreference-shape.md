# actions, functions (generator): createEntityReference() produces { id, logicalName } bodies that the Web API rejects; function @odata.id uses heuristic pluralization
<!-- labels: bug,P1,pkg:actions,pkg:functions,generator -->

## Summary

An entity-typed action parameter must be the entity shape with its primary key, for example
`{"@odata.type":"Microsoft.Dynamics.CRM.account","accountid":"…"}`. For activity types the key is
`activityid`. The SDK's `createEntityReference` and the action body serializer send `id` and
`logicalName`, which are not properties of the entity type:

```
GrantAccess body: {"Target":{"@odata.type":"Microsoft.Dynamics.CRM.account","id":"a1","logicalName":"account"},
                   "PrincipalAccess":{"Principal":{"@odata.type":"Microsoft.Dynamics.CRM.systemuser","id":"u1","logicalName":"systemuser"},…}}
email ref: {"@odata.type":"Microsoft.Dynamics.CRM.email","id":"e1","logicalName":"email"}
```

For function parameters, the entity set is guessed by pluralization. A reference without
`logicalName` (allowed by the interface) becomes `{"@odata.id":"s(2222…)"}`.

## Repro

`repro/gen/06-entityref-and-messages.mjs` and `repro/gen/01-functions-url.mjs` ("RetrievePrincipalAccess ref w/o logicalName").

## Root cause

- The `createEntityReference` template in `tools/generate-sdk-types/src/generators/actions-generator.ts:434-530`
  (`:502`, `getEntitySetNameFromReference` at `:526-527`), and in `functions-generator.ts:509-596`.
- `actions-generator.ts:326-329` copies parameters into the body verbatim.

## Proposed fix

- `createEntityReference(logicalName, id, { primaryIdAttribute?, entitySetName? })` returns the Web
  API shape. Use the generator's CSDL `entitySetMap` and key names, so no runtime pluralization is
  needed. Activity types use `activityid`.
- For function `@odata.id`, require the set name, or resolve it from `entitySetMap`. Throw when it
  can't be resolved.

## Acceptance criteria

- [ ] GrantAccess Target is `{"@odata.type":"Microsoft.Dynamics.CRM.account","accountid":"a1"}`.
- [ ] An email reference uses `activityid`.
- [ ] A reference with an unresolvable set throws.
