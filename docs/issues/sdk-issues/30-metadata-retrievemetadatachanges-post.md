# metadata: retrieveMetadataChanges() sends POST, but RetrieveMetadataChanges is a Web API function (GET)
<!-- labels: bug,P1,pkg:metadata -->

## Summary

`MetadataClient.retrieveMetadataChanges()` sends `POST /RetrieveMetadataChanges` with a JSON body.
RetrieveMetadataChanges is a **function**: the SDK's own CSDL-generated `RetrieveMetadataChangesFunction`
exists, and there is no such action. It must be called with GET and parameter aliases. The JSDoc
example at `:825` also uses `Value: 'account'`, but `MetadataConditionExpression.Value` is typed
`{ Type, Value }`.

`packages/dataverse-sdk-metadata/src/MetadataClient.ts:858-860`

## Proposed fix

Reuse `RetrieveMetadataChangesFunction`: `GET …/RetrieveMetadataChanges(Query=@p1[,ClientVersionStamp=@p2,DeletedMetadataFilters=@p3])?@p1=<json>`.
This depends on the enum and Guid serialization issues. Fix the JSDoc example.
