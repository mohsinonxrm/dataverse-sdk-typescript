# core: without a logger, every request writes console.debug output in production
<!-- labels: bug,P2,pkg:core,browser -->

## Summary

`LoggingMiddleware` falls back to `ConsoleLogger` when no logger is passed. Every request then logs
to `console.debug` (2 calls per request in the repro). That includes the request URL, which, for
FetchXML, contains query values the user typed. In a browser this is noise, and it is a mild
privacy concern if logs are collected.

## Repro (`repro/core.mjs`, case 7)

```
## 7. default logger writes console.debug on every request
 { consoleDebugCalls: 2 }
```

## Root cause

`packages/dataverse-sdk-core/src/middleware/LoggingMiddleware.ts:16`

## Proposed fix

Default to a no-op logger. Make `ConsoleLogger` opt-in (`logger: ConsoleLogger`), and document a
`level` option.
