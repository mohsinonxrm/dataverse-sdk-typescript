# discovery: hard-coded commercial scope, v2.0 response type mismatch, State filter type mismatch, no pipeline or typed errors, unescaped filters
<!-- labels: bug,P1,pkg:discovery,fetchxml-studio -->

## Summary

`DiscoveryClient` (Global Discovery Service) has these problems:

1. **The scope ignores `baseUrl`.** The token scope is always
   `https://globaldisco.crm.dynamics.com/.default`, even when `baseUrl` points to GCC High or DoD.
2. **The response type models the legacy `OrganizationDetail`** (`Endpoints.WebApiUrl`, `Geo`,
   `State: string`). The v2.0 `Instances` response has top-level `Url`, `ApiUrl`, `UrlName`,
   `UniqueName`, `FriendlyName`, `State` (number), `Version`, `LastUpdated`, and optionally
   `Region`, `Purpose`, `TenantId`, `EnvironmentId` and `OrganizationId`.
3. **`getEnabledOrganizations()` filters `State eq 'Enabled'`**, but State is an integer (0 means
   enabled). Expect a 400 response; this hasn't been verified live.
4. **No pipeline.** It uses global `fetch` with no `FetchProvider`, retry or `Retry-After`
   handling, and throws a plain `Error` without a status.
5. **Filter values aren't escaped:** `UniqueName eq 'o'brien'`.

## Why FetchXML Studio needs this

The web app's environment picker lists the user's environments through Global Discovery.

## Root cause

`packages/dataverse-sdk-discovery/src/DiscoveryClient.ts`:

- `:18`: constant scopes.
- `:73-75`: the `baseUrl` override.
- `:135`: global `fetch`.
- `:145-149`: a plain `Error`.
- `:177, :202`: unescaped interpolation.
- `:221`: the State filter.

The legacy `OrganizationDetail` type is at `packages/dataverse-sdk-discovery/src/types.ts:225-302`.

## Proposed fix

- Add a `cloud` preset (`commercial`, `gcc`, `usgovhigh`, `dod`, `china`) that sets the base URL,
  scope and authority hint. Verify the hosts against Microsoft Learn. Otherwise derive the scope
  from the `baseUrl` origin, or accept `scopes`.
- Retype `Instance` per v2.0. Make `getEnabledOrganizations()` use `State eq 0`.
- Accept a `FetchProvider`, or build on `DataverseClient`, to get retry and typed errors. Escape
  `'` as `''`.
- Verify CORS on `globaldisco` from a browser origin and document the result.
