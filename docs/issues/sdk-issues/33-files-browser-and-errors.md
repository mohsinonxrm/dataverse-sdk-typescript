# files: unguarded Buffer.isBuffer throws in browsers, HTTP errors are ignored during upload, the Initialize Target shape is wrong, and the package doesn't build
<!-- labels: bug,P2,pkg:files,browser -->

## Summary

1. **Breaks in browsers.** `Buffer.isBuffer(file)` has no `typeof Buffer` guard, so `upload(blob)`
   throws `ReferenceError: Buffer is not defined` before sending anything. `Buffer` also appears in
   public signatures, which forces `@types/node` on browser consumers.
2. **HTTP errors are ignored.** No step checks `response.ok`, so an upload where every request
   returns 400 **resolves successfully**.
3. **Wrong Initialize Target shape.** The InitializeFileBlocksUpload `Target` is built as
   `{"@odata.type":"Microsoft.Dynamics.CRM.EntityReference","logicalName":"accounts","id":"abc"}`.
   The documented shape is `{"@odata.type":"Microsoft.Dynamics.CRM.account","accountid":"…"}`.
4. **Bypasses auth and the pipeline.** The client takes a raw `RequestAdapter`. The JSDoc example
   uses `client.requestAdapter`, which doesn't exist.
5. **No `dist/` is produced.** `packages/dataverse-sdk-files/dist` is missing after a workspace
   build.

## Repro (`repro/gen/05-files-browser.mjs`, with `delete globalThis.Buffer`)

```
upload(Blob) in Buffer-less env -> ReferenceError: Buffer is not defined | requests sent: 0
Init body: {"Target":{"@odata.type":"Microsoft.Dynamics.CRM.EntityReference","logicalName":"accounts","id":"abc"},…}
upload with 400 responses resolved without error?
```

## Root cause

`packages/dataverse-sdk-files/src/FileColumnClient.ts`:

- `:261`: `Buffer.isBuffer`.
- `:77, :163`: `Buffer` in signatures.
- `:92-97`: the Target shape.
- `:102, :121, :146`: no `ok` checks.
- `:56-58`: the raw adapter.

## Proposed fix

- Accept `Blob | ArrayBuffer | Uint8Array`, and Node's `Buffer` through `Uint8Array`.
- Build the Target from the logical name and primary key.
- Check `response.ok` and throw a parsed OData error.
- Accept a `DataverseClient`.
- Fix the build.

FetchXML Studio doesn't use file columns today, so this is P2 for it.
