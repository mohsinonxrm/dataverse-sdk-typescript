# core: FetchRequestAdapter JSON.stringify()s every body, so string, Blob and ArrayBuffer bodies such as a multipart $batch cannot be sent
<!-- labels: bug,P0,pkg:core,pkg:batch,fetchxml-studio -->

## Summary

`FetchRequestAdapter.send()` always does `body: JSON.stringify(request.body)`. A string body (the
multipart text of a `$batch`) is sent as a quoted, escaped JSON string. Binary bodies are mangled
too. No public API can send a non-JSON body through the pipeline, so auth, concurrency and retry
are lost for those requests.

## Why FetchXML Studio needs this

FetchXML Studio runs record deletes, activate and deactivate, close messages and workflow runs as
OData `$batch` requests of up to 1000 operations. A FetchXML query longer than the URL limit also
has to go through `POST $batch`. Both need a raw `multipart/mixed` body.

## Repro

```js
const body = '--batch_x\r\nContent-Type: application/http\r\n\r\nGET /api/data/v9.2/WhoAmI() HTTP/1.1\r\n\r\n--batch_x--';
await c.send({ method: 'POST', url: `${c.getBaseUrl()}/$batch`, headers: { 'content-type': 'multipart/mixed; boundary=batch_x' }, body });
```

Actual output (`repro/core.mjs`, case 2). The body on the wire starts with a quote character:

```
sentBodyStartsWith: '"--batch_x\\r\\nConten'
```

## Root cause

`packages/dataverse-sdk-core/src/pipeline/FetchRequestAdapter.ts:24`

## Proposed fix

- JSON-stringify only plain objects and arrays.
- Pass `string`, `Blob`, `ArrayBuffer`/`ArrayBufferView`, `FormData`, `URLSearchParams` and
  `ReadableStream` through unchanged.
- Never overwrite an explicit `content-type`. Default to `application/json` only for the JSON
  case.

## Acceptance criteria

- [ ] A string body arrives byte-for-byte unchanged with the caller's `content-type`.
- [ ] Object bodies behave as they do today.
- [ ] Tests cover string, `Uint8Array`, `Blob` and object bodies.

## Workaround in FetchXML Studio until fixed

FetchXML Studio's gateway sends `$batch` with its own `fetch` and a token from the token provider,
bypassing the SDK pipeline.
