# dataverse-sdk-generator: function.ejs serializes parameters with String() (strings unquoted, no enum/Guid/complex handling, bound functions not supported)
<!-- labels: bug,P2,pkg:generator,generator -->

## Summary

The per-org code generator's function template sets aliases with `String(this.x)`:

- strings are not quoted at all;
- enum, Guid, DateTimeOffset and complex parameters get no special handling;
- bound functions aren't handled in the URL.

This was found by reading the template; it has not been executed.

## Root cause

`packages/dataverse-sdk-generator/templates/function.ejs:44` (aliases) and `:53` (URL).

## Proposed fix

Share one parameter serializer between `tools/generate-sdk-types` (after the string, enum and Guid
fixes) and `dataverse-sdk-generator`, so the two generators can't drift.
